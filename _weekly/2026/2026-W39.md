## GEMC3

- Macro option: verified execution follows all starter commands, added Geant4 macro startup with batch
  event control, and added startup-order regression checks.
- Published Callgrinder action — a zero-dependency Node.js GitHub Action and CLI that profiles a command under
  callgrind and reports config-driven per-category and per-routine CEst costs, modelled on ThreadScale.
  Added a from-callgrind summarize path and converted the src, clas12-systems, and clas12Tags profiling
  workflows to run through the action, removing the local valgrind and summary scripts.
- Added a debug-symbols gemc image variant (built on the g4install debug base) to the src Deploy and pointed
  the clas12-systems profiling workflow at it so Geant4/CLHEP routines resolve.
- Fixed the profiling prep step that exited on an empty G4 dataset grep by sourcing geant4-config for the
  dataset variables; gemc finds its Geant4 data through the installed package cache, so those variables are
  no longer exported. Made Callgrinder tolerate an unreadable callgrind file instead of crashing.
- Converted clas12Tags profiling to set up the GEMC2 module environment in the prep step and run gemc
  directly, so only gemc runs under valgrind.
- Generator examples: set both phi-spread examples to a fixed 45° polar angle; increased theta sampling to
  20° and verified signed-angle momentum and cosine bounds; widened the uniform XY view and increased
  Gaussian XY vertex spreads to 4 and 5 mm; centered vertices inside the target with Z and XY emission
  angles; renamed examples and improved vertex visibility with a transparent target and angled beams.
  Simplified vertex cases and angular plots, added 100-event GEMC views for all 11 website examples, then
  documented all 17 tube-target vertex/angular examples with verified plots and interactive geometry
  (Analyzer plots, ~85,000 throws).
- Imported and optimized the HTCC CAD cones: cured the three beamline cones into watertight decimated solids
  and placed them per variation in a separate CAD system that loads from the geometry database.
