## 室外 🛠️

- [ ] **草坪** – 修剪草坪/修整边缘，清理杂物，设置洒水定时器或安排割草服务  
- [ ] 修剪灌木/树木，使其远离外墙板和窗户  
- [ ] 将户外家具和烧烤架放到有遮蔽的地方或搬入室内
- [ ] 关闭燃气烧烤架的阀门
- [ ] 关好并锁好储物棚 / 车库 / 大门  
- [ ] 清空室外垃圾桶和回收桶  
- [ ] 检查檐沟和落水管是否堵塞  

## 安防 🔒

- [ ] 锁好所有门窗（别忘了地下室和天窗）  
- [ ] 设置智能灯/定时器，营造有人在家的样子  
- [ ] 暂停邮件和报纸投递，或安排代收  
- [ ] 告知可信赖的邻居或朋友你的出行日期和联系方式  
- [ ] 将贵重物品收在不易被看到的地方  

## 家用设施 ⚙️

- [ ] 将热水器设为度假 / 低温模式  
- [ ] 拔掉非必要电子设备和小家电的电源插头  
- [ ] 清空并清洁**卫生间**的垃圾桶  

## 厨房 🍽️

- [ ] 运行洗碗机，洗完后取出所有餐具  
- [ ] 清理冰箱里的易腐食物；擦拭搁板并放入一盒小苏打  
- [ ] 清空厨房垃圾和回收物；必要时清洁垃圾桶  
- [ ] 擦拭台面和水槽；放入冰块/柑橘皮并启动厨余垃圾处理器  
- [ ] 清洁咖啡机并晾干，清空咖啡渣  
- [ ] 检查食品储藏柜中是否有可能招引害虫的物品  

## 卫生间 🚿

- [ ] 刷洗马桶，放入缓释洁厕片  
- [ ] 冲洗并擦干洗手盆和浴缸；擦拭玻璃门/镜子  
- [ ] 清洗并收好浴室地垫 / 毛巾，以防发霉  
- [ ] 拉上浴帘或关上淋浴间的门，防止灰尘进入  
- [ ] 向不常用的排水口倒入一杯水，保持 P 型存水弯内有水  
- [ ] 检查洗手盆下方是否有缓慢渗漏  

## 洗衣与卧室 🛏️

- [ ] 洗完所有衣物；清空洗衣机和烘干机  
- [ ] 撤下床上用品，或换上干净床单并将床铺整理好  
- [ ] 关好衣柜门和抽屉  

## 室内日常整理 🏠

- [ ] 吸尘/扫地；快速拖一遍经常走动的区域  
- [ ] 给室内植物浇水或装上自动浇水锥  
- [ ] 更换电量不足的电池（恒温器、烟雾/一氧化碳探测器）  
- [ ] 确认烟雾和一氧化碳探测器在测试时能正常鸣响  
- [ ] 将室内门留一条缝，保持空气流通  

## 出发当天 🚗

- [ ] 清空小垃圾桶，随后将路边的垃圾桶收进车库  
- [ ] 再次确认炉灶/烤箱旋钮处于关闭位置  
- [ ] 按平时的习惯关上百叶窗/拉上窗帘  
- [ ] 确认钱包、护照、药品、充电器都已装好  
- [ ] 关闭灯光（已设置定时程序的除外）和主要吊扇  
- [ ] 最后巡视一遍——然后锁好门，尽情享受旅程！  


## 鸡舍 🐔
- [ ] 确保鸡舍安全并锁好
- [ ] 往喂食器里加足够维持整个出行期间的饲料
- [ ] 加满饮水容器并检查是否漏水
- [ ] 安排人收鸡蛋并查看鸡的情况
- [ ] 为电池供电的摄像头充电

## Gardyn
- [ ] 确保 Gardyn 已设为度假模式
- [ ] 加满储水箱
- [ ] 检查养分水平，必要时补充
