## 屋外 🛠️

- [ ] **芝生** – 芝刈り・縁刈り、落ち葉などの除去、スプリンクラーのタイマー設定または芝刈りサービスの手配  
- [ ] 外壁や窓にかからないよう低木・樹木を剪定する  
- [ ] 屋外の家具とグリルをカバーで覆うか、屋内に入れる
- [ ] ガスグリルのバルブを閉める
- [ ] 物置・ガレージ・門を閉めて施錠する  
- [ ] 屋外のゴミ箱・リサイクル用の回収箱を空にする  
- [ ] 雨どいと縦どいの詰まりを確認する  

## 防犯 🔒

- [ ] すべてのドアと窓を施錠する（地下室や天窓も忘れずに）  
- [ ] 在宅しているように見せるため、スマート照明やタイマーを設定する  
- [ ] 郵便物・新聞の配達を一時停止するか、回収を手配する  
- [ ] 信頼できる隣人や友人に不在期間と連絡先を伝える  
- [ ] 貴重品を外から見えない場所に隠す  

## 設備 ⚙️

- [ ] 給湯器を休暇モードまたは低温モードに設定する  
- [ ] 使用する必要のない電子機器や小型家電のプラグを抜く  
- [ ] **浴室**のゴミ箱を空にして清掃する  

## キッチン 🍽️

- [ ] 食洗機を運転し、洗い終わった食器を取り出す  
- [ ] 冷蔵庫から傷みやすい食品を取り出し、棚を拭いて重曹を箱ごと置いておく  
- [ ] キッチンのゴミ・リサイクル品を出し、必要ならゴミ箱を洗う  
- [ ] カウンターとシンクを拭き、氷や柑橘類の皮を入れてディスポーザーを運転する  
- [ ] コーヒーメーカーを洗って自然乾燥させ、コーヒーかすを捨てる  
- [ ] 害虫を引き寄せそうなものがないかパントリーを確認する  

## 浴室 🚿

- [ ] トイレをこすり洗いし、成分がゆっくり溶け出す錠剤タイプの便器用洗浄剤を入れる  
- [ ] 洗面台と浴槽をすすいで乾かし、ガラスドアや鏡を拭く  
- [ ] バスマット・タオルを洗濯して収納し、カビを防ぐ  
- [ ] ほこりが入らないようシャワーカーテンやドアを閉める  
- [ ] あまり使わない排水口にコップ1杯の水を流し、Pトラップの封水を保つ  
- [ ] 洗面台の下に少量の水漏れがないか確認する  

## 洗濯・寝室 🛏️

- [ ] すべての洗濯を終え、洗濯機と乾燥機を空にする  
- [ ] ベッドのシーツを外すか、清潔なシーツできれいに整える  
- [ ] クローゼットのドアと引き出しを閉める  

## 室内全般 🏠

- [ ] 床に掃除機をかけるか掃き掃除をし、人の通りが多い場所はさっとモップがけする  
- [ ] 室内の植物に水をやるか、土に差し込むタイプの自動給水器を設置する  
- [ ] 残量の少ない電池を交換する（サーモスタット、煙感知器・一酸化炭素検知器）  
- [ ] 煙感知器・一酸化炭素検知器のテスト音が鳴ることを確認する  
- [ ] 空気が循環するよう室内のドアを少し開けておく  

## 出発日 🚗

- [ ] 小さなゴミ箱を空にし、収集後は道路脇に出したゴミ箱をガレージ内に戻す  
- [ ] コンロ・オーブンのつまみがオフになっているか再確認する  
- [ ] いつもどおりにブラインド・カーテンを閉める  
- [ ] 財布、パスポート、薬、充電器を荷物に入れたか確認する  
- [ ] 照明（タイマーなどで設定済みのものを除く）を消し、主なシーリングファンを止める  
- [ ] 最後にもう一度ひと回り点検し、施錠して旅行を楽しもう！  


## 鶏小屋 🐔
- [ ] 鶏小屋の安全が確保され、施錠されているか確認する
- [ ] 不在期間中に十分な量の餌を給餌器に入れる
- [ ] 給水容器を満たし、水漏れがないか確認する
- [ ] 卵の回収と鶏の様子の確認を誰かに頼む
- [ ] 電池式カメラを充電する

## Gardyn
- [ ] Gardyn が休暇モードに設定されているか確認する
- [ ] 貯水タンクを満たす
- [ ] 養分の量を確認し、必要なら補充する
