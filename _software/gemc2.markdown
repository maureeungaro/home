GEMC2 is the second-generation GEMC simulation framework used for CLAS12
detector simulation and Jefferson Lab production workflows.

| Question | Answer |
|:--|:--|
| What is it? | A Geant4 Monte Carlo simulation framework for CLAS12 detector geometry, digitization, and production workflows. |
| Who is it for? | CLAS12 collaborators and users maintaining or reproducing GEMC2-era simulation campaigns. |
| Why use it? | It documents the simulation generation used before the current GEMC3 workflow and remains useful for reproducibility. |
| Where to start? | See the [clas12Tags repository](https://github.com/gemc/clas12Tags) and the [GEMC homepage](https://gemc.github.io/home/). |
