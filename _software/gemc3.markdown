GEMC3 is the current Python-friendly GEMC workflow for building and running
Geant4 detector simulations without writing a full C++ Geant4 application.

| Question | Answer |
|:--|:--|
| What is it? | A Geant4 simulation workflow with Python geometry definition, database-backed configuration, visualization, and analysis outputs. |
| Who is it for? | Detector developers, Jefferson Lab users, CLAS12 simulation users, and scientists prototyping Geant4-based studies. |
| Why use it? | It lowers the entry barrier for detector and radiation-transport simulations while keeping workflows reproducible. |
| Where to start? | Visit the [GEMC homepage](https://gemc.github.io/home/) and review the [GEMC selected talks](/home/gemc/gemc). |
