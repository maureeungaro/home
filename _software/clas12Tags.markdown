The `clas12Tags` repository provides tagged CLAS12 geometry and simulation
releases for GEMC-based production workflows.

| Question | Answer |
|:--|:--|
| What is it? | Versioned CLAS12 simulation releases, geometry tags, and steering material for GEMC production. |
| Who is it for? | CLAS12 collaborators and users who need reproducible Monte Carlo simulation configurations. |
| Why use it? | Tagged releases make it easier to reproduce simulation campaigns and connect results to a known detector configuration. |
| Where to start? | Open the [clas12Tags repository](https://github.com/gemc/clas12Tags) or see [CLAS12 simulations on OSG](/home/osg/osg). |
